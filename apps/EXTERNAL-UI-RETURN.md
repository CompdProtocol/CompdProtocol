# Return the complete frontend source

When UI/UX work is finished, return the complete modified source tree, including the page markup, styles, JavaScript, route/build configuration, and any new frontend assets required to reproduce the work. Do not return only dist or other generated build output.

Do not add API secrets, environment files with real values, production credentials, private keys, wallet/signer material, RPC credentials, or backend implementation. Keep any demo configuration clearly local-only and secret-free.

Include the dependency lockfile and concise run/build instructions for any dependency or tooling changes. Keep the local API paths and response shapes compatible unless the integration owner has reviewed and approved a coordinated change.
