# Contributing

Thanks for helping improve COMPD.

- Keep changes scoped to the relevant package (`apps/interface/`, `packages/agent/`, or `packages/protocol/`).
- Add or update tests for behavior changes.
- Do not include secrets, production configuration, private runtime data, or real user data.
- Do not claim that a test fixture is a live observation or that a local test proves deployment/security.
- Clearly label experimental, prototype, and unverified behavior.
- For contract changes, include the relevant Foundry regression tests and explain any storage, authorization, accounting, or external-call implications.
- For security issues, follow `SECURITY.md` rather than opening a public issue with exploit details.
